# 补剂应用全景综合与决策实战：场景化处方模板、周期化使用与监测一体化

## 核心结论（3-6 条）

1. **补剂方案应"分层叠加"，不要"一锅煮"**：基础层（蛋白、肌酸、维生素 D）+ 性能层（咖啡因、β-丙氨酸、瓜氨酸）+ 恢复层（鱼油、镁、褪黑素）+ 风险层（TRT/AA S 需临床监督）；每层独立判断、不混淆。 [PMID:33097528]
2. **周期化使用（periodization）是补剂科学化的核心**：肌酸可连续使用；咖啡因/β-丙氨酸/碳酸氢钠按训练周期（4-8 周高强度期 + 2-4 周低剂量期）；TRT 不应周期化（持续使用）；OTC 促睾与 AAS 应避免。 [PMID:33097528; doi:10.1186/s12970-020-00383-4]
3. **场景化处方模板**：增肌优先（肌酸 + 蛋白 + 维生素 D + 咖啡因）、力量优先（肌酸 + 咖啡因 + 碳酸氢钠赛前）、耐力优先（咖啡因 + β-丙氨酸 + 电解质 + 碳水凝胶）、减脂优先（高蛋白 + 咖啡因 + 鱼油 + 维生素 D）。 [PMID:33097528]
4. **常见错误与纠正**：未建立基础（睡眠 + 营养 + 训练）就追求"补剂奇迹"；混淆"安全"与"有效"（如咖啡因"安全"但增肌效应小）；过早使用 TRT/AA S（基线优化不足）。 [doi:10.5534/wjmh.190043; PMID:8637535]
5. **监测一体化策略**：使用 Tier 1/Tier 2 补剂不需要血液监测；TRT/AA S 必须严格监测（基线 + 3-6-12 月 + 之后每年）；监测数据驱动剂量与方案调整。 [doi:10.1210/jc.2018-00229]
6. **个体化与"基线优先"原则**：任何补剂在基线睡眠（7-9 h）、营养（1.6-2.2 g/kg/d 蛋白）、训练（≥3 次/周抗阻）、心理（压力 < 中等）达标之前不应进入；补剂放大基线效应而非替代基线。 [PMID:33097528]

## 关键策略（场景化模板与周期化）

### 1) 补剂层级（Layered Supplementation）

| 层级 | 目标 | 成分 | 证据等级 |
| --- | --- | --- | --- |
| **基础层（Foundation）** | 健康维持 + 基础性能 | 足量蛋白、肌酸、维生素 D、镁、睡眠 | A |
| **性能层（Performance）** | 力量/耐力增益 | 咖啡因、β-丙氨酸、瓜氨酸、碳酸氢钠 | A / B |
| **恢复层（Recovery）** | 减少损伤、加快适应 | 鱼油、维生素 D、镁、褪黑素 | B / C |
| **健康层（Health）** | 长期代谢/激素健康 | 锌、维生素 K2、ω-3、复合维生素 | B / C |
| **风险层（Risk）** | 临床监督下使用 | TRT、AAS、生长激素、Peptides | A 风险/有限获益 |

### 2) 增肌优先处方模板（男性，30 岁，3 年训练经验，目标 +2 kg 肌肉/年）

- **训练**：3-4 次/周抗阻训练（Push/Pull/Legs 6 天/week），每肌群 12-16 组/周。
- **营养**：热量盈余 +300 kcal；蛋白 2.0 g/kg/d；碳水 5 g/kg/d；脂肪 1 g/kg/d。
- **补剂**：
  - **基础层**：肌酸 5 g/d；维生素 D3 4000 IU/d + K2 200 µg/d（基线 25(OH)D 监测）；镁 300-400 mg/d（甘氨酸镁或苏糖酸镁）。
  - **性能层**：咖啡因 3-6 mg/kg 训前 30-60 min（高强度训练日）；β-丙氨酸 3.2 g/d × 12 周（可间断）。
  - **恢复层**：鱼油 2-4 g/d（EPA+DHA）；睡眠 7-9 h（必要时褪黑素 0.5-1 mg 睡前 1 h）。
  - **避免**：OTC 促睾、BCAA、GLP-1 RA、二甲双胍、大剂量抗氧化剂。

### 3) 力量优先处方模板（力量举运动员，25 岁，目标 1RM +10%）

- **训练**：4-5 次/周（5/3/1 或 Sheiko 计划）；低次数（1-5 reps）高强度（85-100% 1RM）。
- **营养**：热量维持或微盈；蛋白 2.0-2.4 g/kg/d；碳水 6-8 g/kg/d（糖原储备）。
- **补剂**：
  - **基础层**：肌酸 5-10 g/d（部分研究支持较高剂量）；维生素 D + K2；镁。
  - **性能层**：咖啡因 3-6 mg/kg 赛前；碳酸氢钠 0.2-0.3 g/kg 赛前 60-90 min（关键赛试）。
  - **避免**：TRT（除确诊性腺功能减退）；AAS（健康运动员禁忌）。

### 4) 耐力优先处方模板（马拉松/铁三，35 岁，目标 PB）

- **训练**：周训练量 8-15 h；周期性长距离、节奏跑、间歇。
- **营养**：碳水 6-10 g/kg/d（训日）；蛋白 1.4-1.8 g/kg/d；铁蛋白监测。
- **补剂**：
  - **基础层**：复合维生素、铁、维生素 D（跑者常缺乏）、镁（防肌肉痉挛）。
  - **性能层**：咖啡因 3-6 mg/kg 赛前/赛中（耐力时间 +2-4%）；β-丙氨酸 3.2 g/d × 8 周（4-10 分钟高强度场景）；电解质（钠 500-700 mg/h 长距离）。
  - **赛中**：60-90 g 碳水/h（双转运：葡萄糖 + 果糖 2:1）；咖啡因凝胶（100-200 mg 30-60 min 前）。
  - **恢复层**：鱼油 2 g/d（抗炎）；必要时褪黑素（时差与睡眠）。

### 5) 减脂优先处方模板（30 岁男性，体脂 22% → 15%）

- **训练**：3 次抗阻 + 2-3 次 HIIT/中等有氧；维持瘦体重优先。
- **营养**：热量赤字 −400 kcal/d；蛋白 2.2-2.4 g/kg/d；高蛋白低碳水循环。
- **补剂**：
  - **基础层**：高蛋白（酪蛋白睡前 30 g + 乳清训后 30 g）；肌酸 5 g/d（防肌肉流失）；维生素 D + K2。
  - **性能层**：咖啡因训前（代谢率 +3-4%、脂肪氧化 +10-30%）。
  - **恢复层**：鱼油 2 g/d；镁 300 mg/d（睡眠与肌肉放松）；褪黑素（必要时）。
  - **避免**：GLP-1 RA 单独使用（无抗阻 + 蛋白保障时瘦体重流失 25-40%）；极低热量饮食。

### 6) 中老年处方模板（50+ 男性，目标保持肌肉与代谢健康）

- **训练**：3-4 次/周抗阻 + 2 次有氧；优先抗阻保肌。
- **营养**：蛋白 1.8-2.2 g/kg/d；维生素 D 监测；钙 1000-1200 mg/d。
- **补剂**：
  - **基础层**：肌酸 3-5 g/d（老年人合成抵抗逆转）；维生素 D 4000 IU/d（基线 <20 ng/mL）；蛋白（每餐 0.4 g/kg）。
  - **健康层**：ω-3 2 g/d（心血管）；维生素 B12（萎缩性胃炎）；镁。
  - **关键决策**：如症状性腺功能减退（总睾酮 <300 ng/dL × 2 + 症状）→ 内分泌科评估 TRT。
  - **避免**：AAS（老年人心血管风险更高）；高剂量抗氧化剂。

### 7) 周期化使用模板

| 补剂 | 周期化方案 | 理由 |
| --- | --- | --- |
| **肌酸** | 连续使用 | 长期安全性确认，停止 28 天后肌内库回退 |
| **咖啡因** | 4-8 周高剂量 → 2-4 周低/无 → 重新评估 | 减少耐受性；恢复期评估基线睡眠与焦虑 |
| **β-丙氨酸** | 8-12 周饱和期 → 4 周维持或停用 | 肌肽饱和后维持即可，无积累 |
| **碳酸氢钠** | 仅限关键比赛 1-3 次 | GI 副作用限制长期使用 |
| **维生素 D** | 连续使用至 50-60 ng/mL 维持 | 缺乏症治疗需要持续 |
| **鱼油** | 连续使用或 4 周 ON/OFF | 抗炎持续；但可周期化 |
| **镁** | 连续使用 | 睡眠与肌肉放松 |
| **南非醉茄** | 8-12 周 → 4 周停用 → 重新评估 | 减少 HPA 轴耐受；监测压力指标 |
| **TRT** | **不周期化** | TRT 是激素替代治疗，停止后症状复发 |
| **OTC 促睾** | **避免使用** | 证据不支持有效性，且部分有抑制 HPT 风险 |
| **AAS** | **避免使用** | 多系统毒性证据 A 级 |

### 8) 常见错误与纠正

#### 错误 1：补剂替代训练

- **现象**：依赖"魔法补剂"但训练不规范（组数 <8/周/肌群、强度不够）。
- **纠正**：训练是基础；补剂仅在基础达标后提供 1-15% 的边际增益。

#### 错误 2：混淆"安全"与"有效"

- **现象**：认为"咖啡因安全 = 增肌"。
- **纠正**：安全 ≠ 有效；咖啡因对增肌效应小（ES 0.1-0.3），对耐力显著。

#### 错误 3：过早使用 TRT/AAS

- **现象**：20-30 岁健身者直接进入 TRT/AAS。
- **纠正**：确诊性腺功能减退（症状 + 总睾酮 <300 ng/dL × 2）才考虑 TRT；AAS 在所有年龄段均非健康选择。

#### 错误 4：迷信 OTC 促睾

- **现象**：使用刺蒺藜、DAA、Fenugreek 等期望"促睾增肌"。
- **纠正**：49 项 RCT Meta 显示均无显著效应；健康人 HPT 轴完整时不响应外源草本刺激。

#### 错误 5：监测缺失

- **现象**：使用 TRT/AAS 但拒绝血液/影像监测。
- **纠正**：监测是安全的前提；Hct >54%、PSA >4 ng/mL、PSA 升高 >1.4/年、LVEF <52% 等指标必须追踪。

#### 错误 6："加性叠加"假设

- **现象**：认为肌酸 + 咖啡因 + 瓜氨酸 + β-丙氨酸 + 鱼油 + 维生素 D 同时使用 = 协同效应。
- **纠正**：多数补剂独立作用；少数组合（肌酸 + 咖啡因）有 RCT 验证，多数组合缺乏证据。

### 9) 监测一体化（Decision-Driven Monitoring）

#### 健康使用者（仅 Tier 1/2 补剂）

- **基线评估**：体成分（DXA 一次）；血液学（可选）。
- **每年**：DXA；血脂、血糖、维生素 D。

#### TRT/AA S 使用者

- **基线**：总睾酮/游离睾酮/E2/SHBG/PSA/Hct/LFTs/血脂/HbA1c/25(OH)D；DXA；心脏超声；CACS（>40 岁 + 风险）。
- **3-6-12 月 + 之后每年**：血液学全套；DXA 每年；心脏超声每年；CACS 每 2-3 年（高风险）。

#### 决策驱动的剂量调整

| 指标 | 异常 | 处理 |
| --- | --- | --- |
| **总睾酮** | TRT 后 >1000 ng/dL | 减量 |
| **Hct** | >54% | 减量 + 献血 |
| **PSA** | >1.4 ng/mL 升高/年 | 泌尿科 |
| **HDL** | <40 mg/dL | 减量 + 生活方式 |
| **ALT/AST** | >3× ULN | 停肝毒 AAS |
| **LVEF** | <52% | 立即停用 + 心内科 |

## 证据缺口与争议

1. **补剂的真实"加性效应"**：单组分效应已知，组合效应 RCT 不足。 [PMID:33097528]
2. **个体化处方（基因组/代谢型）**：基因型指导补剂选择仍多在概念阶段。 [PMID:33097528]
3. **长期（>5 年）使用安全性**：Tier 1 补剂 <10 年级数据；Tier 4/5 缺乏长期安全性。
4. **新兴补剂的"灰色市场"**：Peptides、SARM、未申报成分的预工作液（prohormones）；监管与质量控制薄弱。
5. **环境与可持续性**：蛋白粉（乳清）、鱼油（过度捕捞）、肌酸（中国为最大产能国）的环境足迹评估尚未整合。
