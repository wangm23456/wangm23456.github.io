# 证据分级与健身补剂决策指南：循证金字塔、决策树与监测清单

## 核心结论（3-6 条）

1. **循证金字塔四层分类用于补剂评估**：A 级（≥3 项大型 RCT 或 Meta 一致）→ B 级（2 项 RCT 或大样本前瞻队列）→ C 级（小样本/亚组/回顾性）→ D 级（机制/动物实验）；补剂应优先选择 A 级证据支撑的品类。 [PMID:33097528]
2. **健身补剂的 Tier 1 仅 5 类**：一水肌酸、咖啡因、β-丙氨酸、碳酸氢钠、足量蛋白质（1.6-2.2 g/kg/d）；其他声称"促睾""增肌"的补剂普遍缺乏 A 级证据。 [PMID:33097528; doi:10.5534/wjmh.190043]
3. **决策树的核心问题**：目标（增肌 vs 力量 vs 耐力 vs 恢复）→ 基线（营养/激素/睡眠/训练量）→ 预算 → 时间；每个分支映射到不同补剂组合。 [PMID:33097528]
4. **血液学生化监测清单（基线 + 3-6-12 月）**：总睾酮/游离睾酮/雌二醇/SHBG、PSA（>40 岁）、Hct/Hb、ALT/AST/GGT/LDH、血脂四项、空腹血糖/HbA1c、25(OH)D、铁蛋白、TSH、CRP；使用任何促睾或 AAS 类产品前必查。 [doi:10.1210/jc.2018-00229]
5. **影像与器质性监测**：DXA 全身体成分（每年 1-2 次）、心脏超声（基线 + 12 月，TRT/AAS 用户）、CMR 钆延迟强化（长期 AAS 用户）、冠状动脉钙化评分（CACS，>40 岁高风险）、腹部超声（口服 17α-烷化 AAS）。 [PMID:28533317]
6. **核心风险分层与决策阈值**：低风险（营养补充）→ 中风险（蛋白与咖啡因）→ 高风险（激素调节、TRT、AAS）；每层有明确的"进入门槛"和"退出条件"。 [PMID:33097528; doi:10.1210/jc.2018-00229]

## 关键框架（决策与监测）

### 1) 循证金字塔与证据分级

| 等级 | 定义 | 适用结论 | 表达规范 |
| --- | --- | --- | --- |
| **A 级** | ≥3 项大型 RCT 或 Meta 一致结论 | 核心事实与确定性结论 | 直接陈述 |
| **B 级** | 2 项 RCT 或大样本前瞻队列 | 可靠支持性结论 | 直接陈述 |
| **C 级** | 小样本、亚组分析、回顾性队列 | 提示性结论 | "提示/相关"，非单一因果断言 |
| **D 级** | 机制、动物实验、体外 | 推测与机制假说 | "推测/机制假说"，明确物种边界 |
| **U 级** | 尚未完成核验的线索信息 | 线索记录 | 仅供线索记录 |

### 2) Tier 1 健身补剂金字塔（强证据）

- **肌酸（3-5 g/d）**：A 级，ISSN、EFSA 一致立场；瘦体重 +1.0-1.5 kg、1RM +5-8%。 [PMID:40662344]
- **咖啡因（3-6 mg/kg，训前 30-60 min）**：A 级，38 RCT Meta；力量 +3-4%、耐力 +2-4%。 [PMID:30926628]
- **β-丙氨酸（3.2-6.4 g/d × 4-12 周）**：A 级；1-10 分钟运动 +2-3%。 [PMID:38952910]
- **碳酸氢钠（0.2-0.3 g/kg）**：B 级，60-420 秒冲刺 +1-3%，GI 副作用 30%。 [PMID:34503527]
- **足量蛋白质（1.6-2.2 g/kg/d）**：A 级，49 RCT Meta。 [PMC5867436]

### 3) Tier 2 交叉补剂金字塔（条件性或争议性证据）

- **维生素 D3**（4000 IU/d，<20 ng/mL 人群）：A 级肌力效应，但仅在缺乏人群有效。 [doi:10.1016/S2213-8587(18)30265-1]
- **鱼油 EPA+DHA**（2-4 g/d）：B 级抗炎与 DOMS 减轻；C 级长期增肌/力量效应。 [PMID:37460208]
- **L-肉碱**（2-3 g/d）：B 级恢复与 DOMS；D 级肌肥大。 [PMID:37460208]
- **南非醉茄 KSM-66**（300-600 mg/d）：B 级皮质醇与压力；C 级肌力与增肌。 [PMID:42199854]

### 4) Tier 3 警示补剂金字塔（缺乏证据或显著风险）

- **OTC 促睾补剂**（刺蒺藜、DAA、ZMA、Fenugreek）：D 级促睾，证据质量极弱；A 级警告其无效性。 [doi:10.5534/wjmh.190043]
- **二甲双胍**：A 级 −78% 钝化肌肥大，健康人群禁忌。 [PMID:35492586]
- **大剂量抗氧化剂**（VC ≥500 mg、VE ≥400 IU）：A 级钝化肌肥大与线粒体适应。 [PMID:19433800]
- **SARM/PPAR/生长激素促泌剂**：U 级证据与 D 级毒性，新兴风险品类。 [PMID:28533317]
- **超生理 AAS**：A 级短期肌肥大，但 A 级心血管、肝、肾、精神、生殖多系统毒性。 [PMID:28533317; PMID:8637535]

### 5) 临床决策树（按目标分层）

#### 目标 A：最大化自然增肌

1. **基础训练**：抗阻训练 ≥3 次/周、每周 10-20 组/肌群、强度 60-85% 1RM。
2. **基础营养**：热量盈余 +200-500 kcal/d；蛋白 1.6-2.2 g/kg/d；碳水 4-7 g/kg/d；脂肪 1 g/kg/d。
3. **基础恢复**：睡眠 7-9 h；压力管理；铁蛋白 30-300 ng/mL。
4. **Tier 1 补剂**：肌酸 3-5 g/d（必须）；咖啡因 3-6 mg/kg 训前（可选）；β-丙氨酸 3.2 g/d（耐力场景）；蛋白粉（蛋白未达阈值时）。
5. **可选优化**：维生素 D 监测 + 缺乏时 4000 IU/d；鱼油 2-4 g/d（高强度训练期）；南非醉茄 600 mg/d（压力/睡眠差）。
6. **避免**：OTC 促睾、BCAA（蛋白充足时）、大剂量抗氧化剂、二甲双胍。

#### 目标 B：提高力量表现（力量举、举重）

1. **基础训练**：低次数（1-5 reps）× 高强度（85-100% 1RM）；辅助中等次数（6-12 reps）。
2. **基础营养**：与目标 A 类似；热量维持或微盈；蛋白 1.8-2.2 g/kg/d。
3. **Tier 1 补剂**：肌酸（必须）；咖啡因（赛前）；碳酸氢钠（赛前 60-90 min 试验）。
4. **避免**：TRT（除确诊性腺功能减退）。

#### 目标 C：耐力运动（长跑、骑行、铁三）

1. **基础营养**：碳水 6-10 g/kg/d（训日）；蛋白 1.4-1.8 g/kg/d。
2. **Tier 1 补剂**：咖啡因（赛前/赛中）；肌酸（短期冲刺与重复冲刺）；β-丙氨酸（1-10 分钟高强度）。
3. **其他**：电解质（钠 500-700 mg/h 长距离）；凝胶/果胶（60-90 g 碳水/h）。

#### 目标 D：减脂与身体重组

1. **基础训练**：抗阻 + HIIT/中等有氧；蛋白 2.0-2.4 g/kg/d 维持瘦体重。
2. **基础营养**：热量赤字 −300-500 kcal/d；高蛋白优先。
3. **避免**：GLP-1 RA 单独使用（无抗阻训练 + 蛋白保障时瘦体重流失 25-40%）；极低热量饮食（<1200 kcal/d）。

#### 目标 E：确诊性腺功能减退（症状 + 总睾酮 <300 ng/dL × 2）

1. **临床路径**：内分泌科/男科就诊；确诊后启动 TRT。
2. **TRT 方案**：经皮睾酮凝胶 4.7-7.8 g/d 或睾酮酯 100 mg/wk；3 月后复测血清睾酮调整剂量。
3. **监测**：基线 + 3-6-12 月（之后每年）— 总睾酮/游离睾酮/雌二醇/SHBG/PSA/Hct/LFTs/血脂/血糖。
4. **生育保留**：hCG 1000-2000 IU × 2-3/wk + SERM（克罗米芬 25-50 mg/d）。
5. **禁止**：AAS（未医嘱）；自购 TRT；超出 TRAVERSE 试验剂量。

#### 目标 F：肌肥大最大化（接受 AAS 相关风险）

1. **必须条件**：年龄 ≥25 岁（骨骼成熟）；基线血液/影像/心理评估；签署知情同意；预设 cycle 计划与 PCT。
2. **剂量上限**：300-500 mg/wk 睾酮（"中度超生理"）；不推荐 >600 mg/wk；不推荐"stacking"。
3. **监测**：DXA 基线 + 6 月；CMR + CACS 基线 + 12-24 月；血液学每 3 月；精液分析每年。
4. **退出条件**：LVEF <52%、CACS >100、Hct >54%、PSA >4 ng/mL 或 >1.4 ng/mL 升高/12 月、肝酶 >3× ULN、抑郁/自杀意念、肌腱断裂。
5. **强烈不推荐**：口服 17α-烷化 AAS（Stanozolol、Oxymetholone、Stanozolol）；共用针头；超过 2 个 AAS 联用。

### 6) 血液与器质性监测清单

#### 血液学基线 + 季度检查（所有健身 ≥3 次/周且>50 岁或使用 TRT/AAS）

| 检测项 | 用途 | 异常处理 |
| --- | --- | --- |
| **总睾酮** | 基线内分泌状态 | <300 ng/dL 重复确诊 |
| **游离睾酮** | 生物活性睾酮 | <65 pg/mL 提示缺乏 |
| **雌二醇（E2）** | TRT/AAS 监控 | >60 pg/mL TRT 时考虑 AI |
| **SHBG** | 游离睾酮计算 | 高/低均影响游离睾酮解读 |
| **LH/FSH** | HPT 轴状态 | 低/检测不到 → 抑制 |
| **PSA（>40 岁）** | 前列腺监测 | >4 ng/mL 或 >1.4/年升高 → 泌尿科 |
| **Hct/Hb** | 红细胞增多 | TRT >54% → 减量/放血；AAS 同 |
| **ALT/AST/GGT** | 肝功能 | >3× ULN → 停肝毒 AAS |
| **血脂四项** | 心血管风险 | HDL<40 + LDL>130 → 干预 |
| **空腹血糖 + HbA1c** | 代谢状态 | HbA1c>5.7 → 代谢综合征 |
| **25(OH)D** | 维生素 D 状态 | <20 ng/mL 补充；目标 40-60 |
| **铁蛋白** | 铁储备 | <30 影响训练耐受 |
| **TSH** | 甲状腺功能 | >4.5 mIU/L 评估 |
| **hs-CRP** | 炎症标志物 | >3 mg/L 心血管风险 |

#### 影像与器质性（按使用层级）

- **DXA 全身体成分**：每年 1-2 次；TRT/AAS 用户每 6 月。
- **心脏超声**：基线 + 12 月；TRT/AAS 用户每 12 月。
- **CMR 钆延迟强化**：长期 AAS 用户（>2 年）每 2-3 年；早发纤维化评估。
- **冠脉钙化评分（CACS）**：>40 岁 + AAS 使用 ≥2 年或 TRT + 心血管高风险。
- **腹部超声**：口服 17α-烷化 AAS 用户每 12 月。
- **骨密度（DEXA）**：>50 岁 TRT 用户每 2 年。

### 7) 决策阈值的临床整合

- **"进入门槛"**：症状 + 实验室证据 + 风险/获益评估。
- **"持续条件"**：达到预期获益 + 副作用最小 + 监测指标在范围内。
- **"退出条件"**：严重副作用、监测指标越界、长期使用累积风险超过获益。

## 关键 GRADE 证据评级（临床结论 vs 证据等级）

### GRADE 评级体系说明

| GRADE 等级 | 定义 | 表达规范 |
| --- | --- | --- |
| **高 (High)** | 进一步研究不太可能改变估计 | "显著/明确/推荐" |
| **中 (Moderate)** | 进一步研究可能影响估计 | "有效/可能推荐" |
| **低 (Low)** | 进一步研究很可能改变估计 | "可能有效/谨慎使用" |
| **极低 (Very Low)** | 任何估计都不确定 | "证据不足/不推荐" |

## 证据缺口与争议

1. **补剂之间相互作用的循证数据**：肌酸 + 咖啡因、咖啡因 + β-丙氨酸等组合效应 RCT 不足。 [PMID:33097528]
2. **"个体化补剂处方"的真实价值**：基因组、运动表型、代谢型指导补剂选择仍多在概念阶段。 [PMID:33097528]
3. **长期（>10 年）使用的安全性数据**：多数补剂 RCT 8-24 周；10 年级数据不足。 [PMID:33097528]
4. **AAS 周期性使用（Cycling）的科学性**：用户自发 12-16 周 cycle 概念缺乏 RCT 证据。 [PMID:8637535]
5. **新兴补剂品类（Peptides、Nootropics、SARM）的监管与风险**：证据基础极薄弱且监管滞后。 [PMID:28533317]
6. **"运动营养补充剂"与"临床药物"的边界模糊**：TRT、AAS、SARM 在健身房与药品市场之间的灰色地带。 [doi:10.5534/wjmh.190043]
