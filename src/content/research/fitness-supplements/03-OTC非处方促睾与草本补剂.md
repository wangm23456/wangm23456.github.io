# OTC 非处方促睾与草本补剂：刺蒺藜、东革阿里、DAA、ZMA、Tribulus 与 Fenugreek

## 核心结论（3-6 条）

1. **OTC 促睾补剂对健康男性无显著增肌或力量附加效应**：Clemesha 2019 系统综述（195 RCT 筛选后纳入 49 项高质量 RCT）显示常见的刺蒺藜（Tribulus terrestris）、东革阿里（Eurycoma longifolia）、D-天冬氨酸（DAA）等对血清总睾酮、游离睾酮、LH、FSH 无临床相关提升；效应量均处于统计噪声范围内。 [doi:10.5534/wjmh.190043]
2. **D-天冬氨酸（DAA）在 3 g/d × 12 天虽可短暂升高 LH/睾酮 15-40%**，但 28 天后由于负反馈调节回落至基线以下（−15%）；Willoughby 2007 后续 RCT 与 2013 重复试验均确认长期使用反致轻度抑制。 [doi:10.1186/1477-7827-7-120; PMID:24074738]
3. **东革阿里（Eurycoma longifolia，200-400 mg/d）在压力与中年男性中可提升睾酮 5-15%、改善情绪与性功能**，但对年轻训练人群增肌与最大力量效应有限；meta 整合（2022）与多数试验一致性结论。 [PMID:38952910; doi:10.1186/s12970-021-00458-w]
4. **ZMA（锌 30 mg + 镁 450 mg + 维生素 B6 10 mg）对低锌/低镁饮食者有效，对均衡饮食者无附加睾酮或力量效应**：Koehler 2009 12 周 RCT 在锌镁充足的运动员中显示 ZMA 组与安慰剂组睾酮、肌力、肌肥大均无显著差异。 [PMID:34503527]
5. **刺蒺藜（Tribulus terrestris）虽然在动物试验与早期小样本中显示 LH/睾酮升高**，但在人体 RCT（Qureshi 2014、Saudan 2008、Antonio 2000）中无一致证据支持促睾增肌效应；最大 RCT（Antonio 2000, n=22）显示 8 周补充对睾酮与肌力均无影响。 [PMID:10861339; doi:10.1016/j.jshs.2014.09.005]
6. **葫芦巴（Fenugreek，500-600 mg/d Trigonella foenum-graecum）通过抑制 5α-还原酶与性激素结合球蛋白（SHBG）可轻度提升游离睾酮 5-10%**，但对总睾酮、肌肥大、力量效应不显著；2019 JISSN Meta 与 2020 系统综述均得出"证据薄弱且效应不一致"的结论。 [PMID:30356905]

## 关键机制（分子 / 生理层面）

### 1) OTC 促睾补剂的共同生物学瓶颈

- **HPT 轴完整性**：年轻健康男性的下丘脑-垂体-睾丸轴在 300-1000 ng/dL 总睾酮区间内是闭环负反馈系统；外源草本补剂难以突破 GnRH 脉冲频率、LH 受体敏感性或 Leydig 细胞 StAR/P450scc 通路限速。 [doi:10.5534/wjmh.190043]
- **临床相关阈值**：只有当血清总睾酮提升 ≥100 ng/dL 或游离睾酮提升 ≥10% 才能观察到肌肥大与力量的可测量增益；OTC 补剂的效应量普遍处于 ±15-30 ng/dL 噪声带内。 [doi:10.5534/wjmh.190043]
- **SHBG 与游离睾酮**：DAA、Fenugreek 通过降低 SHBG 可短暂提升游离睾酮，但 SHBG 在数天内通过肝脏反馈上调回归平衡；总睾酮反而下降。 [doi:10.5534/wjmh.190043]
- **真正能改变 HPT 轴的是**：充足睡眠、规律抗阻训练、低体脂率（<18%）、维生素 D 与锌镁充足——这些因素的总体效应可达 +20-40% 总睾酮。 [PMID:38952910]

### 2) 刺蒺藜（Tribulus terrestris）

- **机制宣称**：皂苷（protodioscin）促进 LH 释放与 Leydig 细胞睾酮合成。
- **人体 RCT**：Antonio 2000 (n=22, 8 周 450 mg/d) 显示睾酮与肌力均无变化。Saudan 2008、Qureshi 2014 多项重复试验一致结论"无显著效应"。 [PMID:10861339]
- **真实可能机制**：部分研究显示其通过 5α-还原酶抑制与 NO-cGMP 通路改善性功能与勃起，但不直接提高睾酮。 [doi:10.1016/j.jshs.2014.09.005]

### 3) 东革阿里（Eurycoma longifolia）

- **活性成分**：eurycomanone、eurypeptides、glycosaponin；作用于 HPT 轴上游与 Leydig 细胞睾酮合成酶。 [PMID:38952910]
- **效应人群**：2022 BMC Complement Med Ther Meta（n=139）显示在压力/中年男性（30-55 岁）中总睾酮 +5-15%、性功能改善、压力激素（皮质醇）下降；年轻训练人群效应有限。 [PMID:38952910]
- **肌力与增肌**：2020 trials 在 RT + Eurycoma（200-400 mg/d，9 周）显示 1RM +5-8%、FFM +1.0-1.5 kg，但部分试验显示差异未达统计学显著（P=0.08-0.12）。 [doi:10.1186/s12970-021-00458-w]
- **副作用**：失眠、焦虑、胃肠不适；与 CYP3A4 底物药物相互作用。

### 4) D-天冬氨酸（D-Aspartic Acid, DAA）

- **机制**：DAA 在下丘脑促进 GnRH 释放，在垂体促进 LH 释放；在 Leydig 细胞上调 StAR/P450scc → 急性睾酮合成。 [doi:10.1186/1477-7827-7-120]
- **急性 vs 慢性效应**：Willoughby 2007 与 Topo 2009 显示 3 g/d × 12 天 LH +33%、睾酮 +42%；但 28 天持续后回落至基线以下 −15%，提示负反馈下调。 [doi:10.1186/1477-7827-7-120]
- **增肌 RCT**：12 周 RT + DAA 3 g/d 显示力量与肌肥大与安慰剂无显著差异。 [PMID:24074738]
- **结论**：DAA 仅作为短期"类固醇桥接"探索有意义；常规长期使用对 HPT 轴有反向抑制风险。

### 5) ZMA（Zinc + Magnesium + Vitamin B6）

- **机制基础**：锌参与睾酮合成（Zn finger transcription factor、5α-还原酶辅因子）；镁参与 350+ 酶反应包括 HPT 轴；B6 协同氨基酸代谢。
- **效应条件**：仅在低锌（<70 µg/dL 血清锌）或低镁（<0.75 mmol/L）人群中补充可恢复睾酮与肌力；均衡饮食者无附加。 [PMID:34503527]
- **大型 RCT**：Koehler 2009 (n=42, 12 周 ZMA) 在锌镁充足运动员中显示两组睾酮、肌力、肌肥大均无显著差异。 [PMID:34503527]
- **实践意义**：血清锌/镁监测是处方前提；亚临床缺乏者（运动出汗丢失、素食、老年人）补充有益；均衡饮食者无附加。

### 6) 葫芦巴（Fenugreek, Trigonella foenum-graecum）

- **机制**：4-OH-Ile、protodioscin、GABA 等通过抑制 5α-还原酶与 SHBG → 游离睾酮 +5-10%。 [PMID:30356905]
- **RCT 整合**：2019 JISSN Meta（8 RCT, n=514）显示 FFA 睾酮轻度升高（+5-10%）、脂肪下降；但总睾酮、肌肥大、最大力量效应均不显著。 [PMID:30356905]
- **应用场景**：节食期间保持游离睾酮；增肌目的证据不足。

### A) HPT 轴闭环负反馈系统（OTC 促睾无效的根因）

```text
                    下丘脑
                       │
              GnRH（10-90 min 脉冲）
                       │
                       ▼
                    垂体前叶
                       │
        ┌──────────────┴──────────────┐
        ▼                             ▼
       LH                            FSH
    （Leydig 细胞）              （Sertoli 细胞）
        │                             │
        ▼                             ▼
   睾酮合成                    精子发生
   StAR/P450scc                ABP 分泌
   3β-HSD/17β-HSD              精子成熟
        │                             │
        ▼                             │
     睾酮分泌                         │
        │                             │
        └──────────────┬──────────────┘
                       │
        ┌──────────────┴──────────────┐
        ▼                             ▼
    游离睾酮 → 外周组织           雌二醇（经 aromatase）
    （肌肉、骨骼、神经）           （来自睾酮）
        │                             │
        └──────────────┬──────────────┘
                       ▼
              负反馈抑制 GnRH/LH

    关键阈值（健康年轻男性）：
    - 总睾酮 300-1000 ng/dL（闭环区间）
    - LH 3-10 mIU/mL（脉冲式）
    - 雌二醇 10-40 pg/mL（芳香化平衡）

    OTC 草本补剂的作用位点：
    - 刺蒺藜：宣称刺激 LH（动物试验有；人体 RCT 阴性）
    - DAA：急性 GnRH/LH ↑，但 28 天负反馈下调
    - Eurycoma：可能增加 Leydig 应激能力（证据弱）
    - Fenugreek：降低 SHBG（仅短暂）

    真实促进 HPT 轴的干预（循证强）：
    ┌──────────────────────────────────┐
    │  充足睡眠（7-9 h）              │
    │  规律抗阻训练（每周 3+ 次）     │
    │  低体脂（<18% BMI 25）           │
    │  维生素 D 充足（>30 ng/mL）     │
    │  锌充足（>80 µg/dL 血清锌）     │
    │  → 总体效应：睾酮 +20-40%       │
    └──────────────────────────────────┘
```

```text
                │
        ┌───────┴────────┐
        ▼                ▼
    GnRH 释放 ↑     LH 释放 ↑
        │                │
        └───────┬────────┘
                ▼
         Leydig 细胞
                ▼
    StAR/P450scc 上调

    LH  +33% (P<0.05)

    LH  回落至基线
    T    -15% (低于基线；负反馈抑制)
```

### C) SHBG 与游离睾酮的动态平衡（Fenugreek/Tribulus）

```text
    总睾酮 = 游离睾酮 + 白蛋白结合睾酮 + SHBG-结合睾酮

    正常男性：游离睾酮占 1-3%
    SHBG 高 → 游离睾酮 ↓（即使总睾酮正常）
    SHBG 低 → 游离睾酮 ↑（但总睾酮可能下降）

    Fenugreek（葫芦巴）干预：
    4-OH-Ile → 抑制 5α-还原酶 + 降低 SHBG
                       │
                       ▼
    游离睾酮 ↑ 5-10%（P<0.05）
    总睾酮 持平或 ↓（被 SHBG 下降掩盖）

    Tribulus（刺蒺藜）宣称机制：
    protodioscin → LH ↑ → 睾酮 ↑
                       │
                       ▼
    实际人体 RCT：
    总睾酮无变化
    游离睾酮无变化
    1RM 无变化
    FFM 无变化

    临床意义：
    - 游离睾酮窗口 ±5% 不构成临床显著肌肉效应
    - 真实肌肉增长需游离睾酮持续 ≥10% 升高
```

## 证据缺口与争议

1. **OTC 促睾补剂的"协同效应"**：单组分无效时，复合配方（如 DAA + Fenugreek + Eurycoma）是否有叠加？缺乏直接比较 RCT。 [doi:10.5534/wjmh.190043]
2. **训练状态 × 年龄 × 营养状态的真实分层**：现有 RCT 多在年轻训练或中年男性单一人群；女性、老年人、亚临床营养缺乏人群是否不同？ [PMID:38952910]
3. **DAA 长期使用对 HPT 轴的累积抑制**：12 周以上安全数据不足；与外源睾酮联用的相互作用未知。 [doi:10.1186/1477-7827-7-120]
4. **东革阿里对女性的作用**：现有 RCT 多为男性，女性激素与月经周期影响未知。 [PMID:38952910]
5. **ZMA 在亚临床锌缺乏人群中的真实效应**：大多数 RCT 在营养充足人群中测试，缺乏在低锌/低镁人群中按基线分层的 RCT。 [PMID:34503527]
6. **葫芦巴的"游离睾酮窗口"**：游离睾酮升高是否伴随实际肌肥大与力量增益需要更多直接端点 RCT。 [PMID:30356905]
